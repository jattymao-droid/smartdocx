# 文库模块 — 设计开发文档







> 版本：v0.1  



> 日期：2026-07-09  



> 目标：在智慧题库门户中新增「文库」能力，支持 doc/docx/ppt/pptx/xls/xlsx/pdf/txt 等文档的上传、管理与在线预览，体验对标 [百度文库](https://wenku.baidu.com/) 核心流程。







---







## 1. 背景与目标







### 1.1 背景







当前系统以「选题 / 组卷 / 题库」为主，教师与教研人员仍大量依赖 Word、PPT、Excel、PDF 等资料。这些文件分散在个人电脑或网盘，无法在平台内统一检索、预览与分享。







### 1.2 产品目标







| 维度 | 目标 |



|------|------|



| 上传 | 支持常见办公文档批量上传，单文件上限可配置（默认 50MB） |



| 预览 | 浏览器内在线阅读，无需下载安装 Office |



| 检索 | 按标题、学科、标签、上传者、格式筛选 |



| 权限 | 公开 / 校内 / 仅本人 / 指定角色，可配置是否允许下载 |



| 体验 | 列表 → 详情 → 预览 → 收藏/下载，流程与百度文库一致 |







### 1.3 非目标（首版不做）







- 在线协同编辑（OnlyOffice 全功能编辑可列为二期）



- 付费下载、积分、创作者分成



- OCR 全文检索（可二期接入现有 OCR 能力）



- 移动端独立 App（先做响应式 Web）







---







## 2. 用户与场景







### 2.1 角色







| 角色 | 能力 |



|------|------|



| 访客（未登录） | 浏览公开文档列表；预览公开文档（可配置水印） |



| 教师（登录） | 上传、管理自己的文档；收藏；下载（受权限控制） |



| 教研员 / 管理员 | 审核、推荐、置顶；管理分类与标签；删除违规文档 |



| 超级管理员 | 存储策略、预览服务、格式白名单、全局配置 |







### 2.2 典型场景







1. **上传课件**：教师上传 `必修一 牛顿定律.pptx`，选择学科「物理」、分类「课件」，设为「校内可见」。



2. **在线阅读**：学生在门户「文库」中搜索「牛顿定律」，点击进入预览页，分页/滚动阅读。



3. **资料沉淀**：教研组批量上传期末复习 PDF，管理员审核后「推荐」到首页。



4. **安全管控**：含答案的 docx 设为「仅本人」，禁止下载，预览带用户名水印。

## 3. 功能范围







### 3.1 门户端（`/library`）







```



首页（推荐 / 最新 / 热门）



  ├── 分类浏览（学科 × 文档类型 × 自定义分类）



  ├── 搜索（标题、标签、上传者）



  ├── 文档详情页（元信息 + 预览区 + 相关推荐）



  └── 我的文库（我上传的 / 我收藏的）



```







**对标百度文库的页面要素：**







- 列表卡片：封面缩略图、标题、页数、格式图标、阅读量、上传时间、上传者



- 详情页：左侧/上方预览，右侧元数据（页数、大小、格式、标签、简介）



- 工具栏：放大/缩小、全屏、页码跳转（PDF/PPT）、收藏、下载（权限允许时）



- 面包屑：首页 / 文库 / 分类 / 文档标题







### 3.2 管理端（`/admin/education/library`）







- 文档列表（审核状态、可见范围、存储路径）



- 审核（通过 / 驳回 + 原因）



- 分类与标签管理



- 推荐/置顶配置



- 存储与预览服务健康检查



- 违规文档下架







### 3.3 上传







| 能力 | 说明 |



|------|------|



| 单文件上传 | 拖拽 / 点击，进度条 |



| 批量上传 | 多选，队列上传，失败可重试 |



| 格式校验 | 扩展名 + MIME 双重校验 |



| 元数据表单 | 标题、简介、学科、分类、标签、可见范围、是否允许下载 |



| 封面上传 | 可选；未上传则从首页自动生成缩略图 |







**支持格式（首版）：**







| 扩展名 | MIME（参考） | 预览策略 |



|--------|--------------|----------|



| pdf | application/pdf | 浏览器 pdf.js 原生渲染 |



| txt | text/plain | 前端 `<pre>` + 编码检测（UTF-8/GBK） |



| docx | application/vnd.openxmlformats-officedocument.wordprocessingml.document | 前端 `docx-preview`（项目已有） |



| doc | application/msword | 服务端转 PDF/HTML 后预览 |



| ppt / pptx | presentation | 服务端转 PDF 或图片序列 |



| xls / xlsx | spreadsheet | 服务端转 HTML 或 PDF；或前端 SheetJS 只读表格 |







> **doc / ppt / xls 等旧格式** 必须经服务端转换，不建议纯前端解析。

### 4.1 总体架构







```

│  - 文库列表 / 详情 / 预览组件                                │

│  /system/education/library/**  → ruoyi-system                │



│  /file/**                      → ruoyi-file                  │

└──────────────────────────┬──────────────────────────────────┘

        ▼                  ▼                  ▼



  ruoyi-system        ruoyi-file         预览转换服务

  PostgreSQL          本地盘 / MinIO      缓存 PDF/HTML/缩略图



```







### 4.2 与现有模块的关系







| 现有能力 | 文库复用方式 |



|----------|--------------|



| `ruoyi-file` `POST /file/upload` | 原始文件上传，返回 `/statics/...` URL |



| `SysCommonController` `/common/upload` | 封面、小附件可走 education 本地路径 |



| `docx-preview` + `DocxPreviewCanvas` | docx 客户端预览参考实现 |



| `portalBanner.js` `resolvePortalMediaUrl` | 统一静态资源 URL 解析 |



| `EduSubject` 学科表 | 文档关联 `subject_id` |



| 门户 `PortalNav` | 新增「文库」导航项 |







### 4.3 预览服务选型（推荐）







**方案 A — kkFileView（推荐，国内项目成熟）**







- 独立 Docker 部署，Java 生态与 RuoYi 契合



- 支持 office / pdf / 图片 / 文本 等在线预览



- 通过 URL 传参：`/onlinePreview?url=encode(base64(fileUrl))`



- 优点：开发量小、格式覆盖全  



- 缺点：多一个服务依赖，需内网可达文件 URL







**方案 B — LibreOffice Headless + 缓存**







- `ruoyi-system` 异步任务：`soffice --headless --convert-to pdf`



- 转换结果写入 `file.path/preview/{docId}.pdf`



- 优点：可控、无第三方 UI  



- 缺点：需维护转换队列、旧格式兼容性







**方案 C — 混合（建议分期）**







| 阶段 | 策略 |



|------|------|



| P0 | pdf.js + txt + docx-preview（零后端转换） |



| P1 | 接入 kkFileView 覆盖 doc/ppt/xls |



| P2 | 异步预转换 + CDN 缓存 + 全文检索 |







本文档后续 API 与表结构按 **方案 C** 设计，预留 `preview_type`、`preview_url`、`convert_status` 字段。

```sql



create table if not exists edu_library_document (



    document_id       bigserial primary key,

    title             varchar(200) not null,

    view_count        integer not null default 0,



    favorite_count    integer not null default 0,



    convert_status    varchar(20) not null default 'none',  -- none/pending/success/failed



    preview_type      varchar(20),                        -- pdf/html/kkfileview/image

    audit_remark      varchar(500),

    create_time       timestamp default current_timestamp,

create index idx_library_doc_subject on edu_library_document (subject_id, del_flag, audit_status);
```

### 6.3 核心业务逻辑







**上传流程**







```



1. 前端 POST /file/upload → 得到 fileUrl



2. 前端 POST /education/library/document → 写入元数据，convert_status=pending



3. 异步任务 EduLibraryConvertTask：



   - pdf/txt/docx → 直接标记 success，设置 preview_type



   - 其他 → 调用 kkFileView 或 LibreOffice 转换



   - 生成 cover 缩略图（PDF 首页 / PPT 首页）



4. 更新 preview_url、page_count、convert_status



5. 若开启审核，audit_status=0，门户不可见直至通过



```







**可见性过滤（列表/详情）**







```java



// 伪代码



if (visibility == PUBLIC) show;



else if (visibility == SCHOOL && isLoggedIn()) show;



else if (visibility == PRIVATE && isOwner()) show;



else if (visibility == ROLE && hasRole()) show;



else 403 / 不在列表出现;



```







**下载控制**







- `allow_download = 0`：仅预览，预览 iframe 禁右键 + 水印；不提供下载 API



- `allow_download = 1`：GET `/document/{id}/download` 鉴权后 302 到文件 URL 或流式输出







### 6.4 异步转换







使用现有 `ruoyi-job` 或 Spring `@Async`：

```java
public void convertAsync(Long documentId) {

    // 4. 失败写 preview_error，支持管理端「重新转换」



}
```

### 7.4 预览组件设计

```vue
computed previewComponent() {
```

## 8. 安全与合规







| 项 | 措施 |



|----|------|



| 文件类型 | 扩展名白名单 + MIME 检测 + 文件头魔数 |



| 大小限制 | `spring.servlet.multipart.max-file-size` + 业务校验 |



| XSS | txt/html 预览转义；禁止上传 `.html/.htm/.svg`（或单独策略） |



| 鉴权 | 预览 URL 使用带签名的临时链接（有效期 15min），避免裸链泄露 |



| 版权 | 上传时勾选「确认拥有版权或授权」；举报入口（二期） |



| 审计 | 上传/下载/删除写操作日志 `@Log` |

## 17. 腾讯云 COS 配置说明

### 17.1 ruoyi-file（config/ruoyi-file-dev.yml）

`yaml
file:
  storage-type: cos

cos:
  secret-id: AKIDxxxxxxxx
  secret-key: xxxxxxxx
  region: ap-guangzhou
  bucket-name: your-bucket-1250000000
  domain: https://cdn.example.com
  prefix: library
`

### 17.2 文库元数据（ruoyi-system-dev.yml）

`yaml
edu:
  library:
    storage:
      type: cos
`

### 17.3 控制台要点

- 创建 COS 存储桶，配置 CAM 子账号密钥
- 浏览器预览需配置 CORS
- kkFileView 需能访问文件公网 URL
